## Избранные проекты

### [Прогнозирование текучести кадров](https://github.com/TrikZ991/hr-attrition-prediction)

На синтетических данных IBM сравнил пять моделей прогноза увольнений. Логистическая регрессия показала **ROC-AUC 0,812** на тестовой выборке. Затем рассчитал, при каком охвате сотрудников программа удержания может окупиться, и сравнил три сценария затрат и эффекта.

[Исследование в Jupyter](https://github.com/TrikZ991/hr-attrition-prediction/blob/main/notebooks/attrition_research.ipynb) · [График окупаемости](https://github.com/TrikZ991/hr-attrition-prediction/blob/main/images/fig4_roi.jpg)

### [Отток клиентов телеком-компании](https://github.com/TrikZ991/churn-prediction)

Во время практики в Setec построил модель на открытых данных IBM Telco. Проверил, какую часть оттока охватывает группа высокого риска. На тестовой выборке в неё попали **34% клиентов, включая 71% всех ушедших**.

[Исследование в Jupyter](https://github.com/TrikZ991/churn-prediction/blob/main/research.ipynb)

### [Прогнозирование свойств композитов](https://github.com/TrikZ991/composite-properties-prediction)

Проверил, можно ли по составу материала предсказать его прочность и модуль упругости. На кросс-валидации самый точный результат для обоих свойств дал **простой прогноз по среднему**. Исследовал этот результат с помощью перестановочного теста и собрал приложение в Streamlit для сравнения прогнозов.

[Исследование в Jupyter](https://github.com/TrikZ991/composite-properties-prediction/blob/main/notebooks/composites_research.ipynb) · [Код приложения](https://github.com/TrikZ991/composite-properties-prediction/blob/main/app.py)
